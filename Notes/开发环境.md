# Part 1 开发环境

## 一、语言与 IDE 的选择

| 选择 | 我的决定 | 理由 |
| --- | --- | --- |
| 编程语言 | **Python** | 语法简单、上手快；FastAPI 写接口很直接；我的开发环境在 WSL 里，Python 开箱即用（WSL 里没装 JDK，Java 要额外折腾） |
| IDE | **VS Code** | 一个编辑器写 Python/Markdown/Shell 都够用，改完直接在集成终端里跑，不用来回切窗口 |

> 题面说“在 Linux 中做完所有事是一个加分项”——我是全程在 **WSL2 (Ubuntu)** 里做的，
> 代码、终端、服务、Git 都在 Linux 侧。

## 二、环境搭建过程

```bash
# 1) 确认 Python 和 git
python3 --version     # Python 3.14.4
git --version         # git 2.53.0

# 2) 建虚拟环境（把依赖装在项目里，不污染系统 Python）
python3 -m venv ~/venvs/jotangnote
source ~/venvs/jotangnote/bin/activate

# 3) 装 Web 框架 FastAPI 和服务器 uvicorn
pip install fastapi "uvicorn[standard]"
```

## 四、任务 2：FastAPI 应用 + /hello 接口

代码（`Project/src/main.py`，节选）：

```python
from fastapi import FastAPI
from fastapi.responses import PlainTextResponse

app = FastAPI(title="JotangNote", version="0.1.0")


@app.get("/hello", response_class=PlainTextResponse)
def hello() -> str:
    return "Hello World From Web Application!"
```

启动：

```bash
cd Project/src
uvicorn main:app --host 0.0.0.0 --port 8080
```

浏览器访问 `http://localhost:8080/hello` 的结果截图：

## 五、这中间踩到的坑 / 学到的东西

1. **为什么要用虚拟环境**：系统 Python 装包要么需要管理员权限，要么把系统环境污染掉。
   虚拟环境是项目级的一套依赖，删掉就等于“重装”，非常干净。
2. **`uvicorn main:app` 是什么意思**：`main` 是模块（`main.py`），`app` 是里面那个 `FastAPI()` 实例；
   uvicorn 是 ASGI 服务器，负责监听端口、把 HTTP 请求交给 FastAPI 处理（框架本身不监听端口）。
3. **`--host 0.0.0.0` vs `127.0.0.1`**：`127.0.0.1` 只接受本机连接；`0.0.0.0` 监听所有网卡。
   我在 WSL 里跑服务、想在 Windows 浏览器里访问，所以要绑 `0.0.0.0`
   （WSL 开了 mirrored 网络模式，`localhost` 是两边共用的）。
4. **端口被占用**：改 `--port` 换一个端口即可；`ss -ltnp | grep 8080` 能看是谁占着。
5. **FastAPI 自带接口文档**：访问 `/docs` 就能看到自动生成的 Swagger UI，写接口时调试很方便——
   这也是我选 FastAPI 而不是纯 Flask 的原因之一。
